プライバシーポリシー

観音台コミュニティが運営する自動化ツールにおける、個人情報の取り扱いについて説明します。

🎯 対象となるツール

このポリシーは、観音台コミュニティの有志が運営する以下の自動化ツール（Gmail API を利用）に適用されます。

  • 集会所予約メール自動処理ボット — 集会所予約に関するメールを読み取り、予約情報を更新します
  • 電子回覧メール配信ツール — 電子回覧のお知らせを配信専用メーリングリストに送信します

📋 取得・利用する情報

上記ツールは、Gmail API を通じて次の情報のみを取り扱います。

  • 集会所予約に関するメールの本文・差出人アドレス（予約内容の抽出・処理のため）
  • 電子回覧の配信を希望した方のメールアドレス（配信専用メーリングリストの管理のため）

氏名や住所など、メールアドレス以外の個人情報は収集・保有しません。

🔒 情報の管理

取得した情報は、上記の目的以外に利用しません。第三者への提供・販売は行いません。
処理は GitHub Actions（非公開リポジトリ）上で実行され、メールの送受信には運営者の Gmail アカウントのみを使用します。

🗑️ 削除・配信停止のご希望

電子回覧の配信停止、またはメールアドレスの削除をご希望の場合は、 こちらの連絡先 までご連絡ください。
