# PWA (Progressive Web App) 対応について

## 概要

観音台コミュニティ情報サイトをPWA（Progressive Web App）に対応しました。

## PWAとは

従来のウェブサイトに以下の機能を追加したもの：
- **ホーム画面に追加**: スマホのホーム画面にアイコンを配置してアプリのように起動
- **オフライン閲覧**: 一度訪問したページはオフラインでも閲覧可能
- **高速読み込み**: キャッシュを活用した高速表示
- **アプリ風の表示**: URLバーなしの全画面表示（スタンドアロンモード）

**注意**: ブラウザの自動「ホーム画面に追加」プロンプトは**抑制**されています。  
ユーザーが自分でホーム画面に追加する必要があります（強制インストールなし）。

## 従来のアクセス方法との互換性

**既存のアクセス方法は完全に維持されます**：
- ブラウザでのURLアクセスは従来通り
- ブックマークも有効
- PWA機能は**オプション**（使いたい人だけ使える）

## 導入されたファイル

```
docs/
  manifest.json          # アプリ設定ファイル
  service-worker.js      # オフライン対応・キャッシュ管理
  icons/
    icon-192.png         # アプリアイコン (192x192)
    icon-512.png         # アプリアイコン (512x512)
    README.md            # アイコンについての説明
  generate_icons.py      # アイコン生成スクリプト
```

## 変更されたファイル

以下のHTMLファイルに、PWA関連のタグとスクリプトを追加：
- `index.html` — manifestリンク
- `top.html` — manifestリンク + Service Worker登録
- `hall-reserve.html` — manifestリンク + Service Worker登録
- `about_this_site.html` — manifestリンク + Service Worker登録

## 使い方

### ユーザー側

1. **従来通りブラウザで閲覧**（何も変わらない）
   - https://kannondai.github.io/kannondai-community/

2. **PWAとして使う場合**（任意）:

#### 方法1: トップページの「アプリとして使う」ボタン（推奨）
   - トップページ（top.html）のヘッダーに「📱 アプリとして使う」ボタンが表示されます
   - ボタンをクリック/タップすると、インストール確認が表示されます
   - 「インストール」を選択すると、ホーム画面にアイコンが追加されます
   - **注意**: iOSでは表示されません（方法2を使用）

#### 方法2: ブラウザの標準機能を使用

### iOS (Safari)
1. サイトを開く
2. 共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選択

### Android (Chrome)
1. サイトを開く
2. メニュー（⋮）→「アプリをインストール」または「ホーム画面に追加」
3. または、トップページの「📱 アプリとして使う」ボタンを使用（推奨）

## アンインストール方法

PWAとして追加したアプリを削除する方法：

### iOS (Safari)
1. ホーム画面でアイコンを長押し
2. 「Appを削除」を選択
3. 確認画面で「削除」をタップ

または：
1. アイコンを長押し → 編集モード（アイコンが揺れる）
2. アイコンの左上の「×」ボタンをタップ
3. 「削除」を選択

### Android (Chrome/Edge)
1. ホーム画面でアイコンを長押し
2. 「アンインストール」または「削除」を選択

または：
1. 設定 → アプリ → 「観音台」を検索
2. アプリを選択 → 「アンインストール」

### デスクトップ (Chrome/Edge)
1. ブラウザで `chrome://apps/` または `edge://apps/` にアクセス
2. 「観音台」アプリを右クリック → 「削除」

または：
1. インストール済みPWAウィンドウを開く
2. メニュー（⋮）→ 「観音台をアンインストール」

### 📌 通常のアプリとの違い

**操作は通常のアプリのアンインストールとほぼ同じですが、以下の点が異なります**：

| 項目 | 通常のアプリ | PWA（このサイト） |
|------|------------|-----------------|
| **アンインストール操作** | 同じ（長押し→削除） | 同じ（長押し→削除） |
| **完全削除** | ✅ アプリとデータが完全に削除される | ⚠️ ブラウザのキャッシュは残る可能性あり |
| **削除後の利用** | ❌ 使えなくなる | ✅ ブラウザから引き続きアクセス可能 |
| **再インストール** | アプリストアから再ダウンロード | サイトを開いてボタンを押すだけ |
| **容量** | 通常は数MB〜数百MB | 非常に小さい（1MB未満） |

**つまり**: PWAのアンインストールは「ホーム画面のショートカットを削除する」に近く、サイト自体は残ります。
いつでもブラウザで https://kannondai.github.io/kannondai-community/ にアクセスできます。

### 🧹 完全にクリアしたい場合（キャッシュ削除）

PWAを削除した後、キャッシュも完全にクリアしたい場合：

#### iOS (Safari)
1. 設定 → Safari → 履歴とWebサイトデータを消去
2. または、設定 → Safari → 詳細 → Webサイトデータ → kannondai.github.io を削除

#### Android (Chrome)
1. Chrome → メニュー（⋮）→ 設定 → プライバシーとセキュリティ
2. 「閲覧履歴データの削除」→「キャッシュされた画像とファイル」を選択
3. または、サイト設定 → kannondai.github.io → ストレージをクリア

**注意**: キャッシュを削除しても、次回アクセス時に自動的に再キャッシュされます（PWAの仕組み）。

## アイコンのカスタマイズ

現在のアイコンは仮のデザインです。正式なデザインに変更する場合：

1. 192x192ピクセルと512x512ピクセルのPNG画像を用意
2. `docs/icons/icon-192.png` と `docs/icons/icon-512.png` を置き換え
3. コミット・プッシュ

または、`generate_icons.py` を編集してデザインを変更し、再実行：

```powershell
cd docs
python generate_icons.py
```

## キャッシュ戦略

Service Workerは以下のファイルをキャッシュします：
- HTMLページ (top.html, hall-reserve.html, about_this_site.html)
- CSS (styles/*.css)
- JavaScript (scripts/*.js)
- その他、初回訪問時に読み込まれたファイル

**キャッシュの更新**:
- ファイルを更新すると、次回訪問時に自動的に新しいバージョンを取得
- Service Workerのバージョン（`CACHE_NAME`）を変更すると強制的に全キャッシュを更新

## 今後の拡張可能性

PWA基盤が整ったので、以下の機能を追加可能：
- **カスタムインストールボタン**: サイト内に「アプリとして追加」ボタンを配置（現在は`deferredPrompt`として保存済み）
- **プッシュ通知**: 新しい回覧やお知らせを通知
- **バックグラウンド同期**: オフライン時の操作を自動同期

## トラブルシューティング

### Service Workerが登録されない
- ブラウザの開発者ツール（F12）→ Consoleタブでエラーを確認
- HTTPSまたはlocalhostでのみService Workerは動作（GitHub Pagesは対応済み）

### キャッシュが更新されない
- ブラウザの開発者ツール → Application → Service Workersで「Unregister」
- キャッシュをクリアしてページを再読み込み

### アイコンが表示されない
- `docs/icons/` ディレクトリにicon-192.pngとicon-512.pngが存在するか確認
- manifest.jsonのパスが正しいか確認
